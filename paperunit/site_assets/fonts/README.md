# Fonts

These webfonts are self-hosted so the generated site makes no external requests.

- **Newsreader** — Copyright 2020 The Newsreader Project Authors, SIL Open Font License 1.1.
- **IBM Plex Sans** / **IBM Plex Mono** — Copyright 2017 IBM Corp., SIL Open Font License 1.1.

Latin subsets only, served as woff2. Fonts are part of the visual layer and are
not required to read the registry; the CSS falls back to system serif, sans and
monospace stacks.
