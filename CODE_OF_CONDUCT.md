# Code of Conduct

paperunit adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, assume good faith, critique artefacts rather than
people, and do not use the project to harass authors, reviewers, or other
contributors. The project audits published artefacts; it does not adjudicate
personal conduct or intent.

## Enforcement

Report unacceptable behaviour privately to the maintainer (pseudonym 无常)
through the repository's private reporting channel (or, when GitHub is used, the
"Report abuse" / private security advisory flow). Reports are handled
confidentially by the maintainer and, where a second maintainer is available, by
both. Enforcement follows the ladder in [OPS.md](OPS.md) §4.6:
clarification, warning, temporary ban, permanent ban.

## Scope

This code applies in project spaces (issues, pull requests, discussions,
registry reports) and when representing the project elsewhere.
